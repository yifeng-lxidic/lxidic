# Lxidic signal and cognition lab

English interactive laboratory with the Lxidic Phi logo, a 14,400-particle cortex, sleep timing, personal physiology and a separately entered task reference example.

All example records are fictional. Calculations run locally in the browser, with no data submission, external scripts or dependencies.

The expandable research view uses the project's v1.1 calibrated coefficients, frozen on November 26, 2026. It shows age/sex-only or personal-reference examples for a task composite and plasma Aβ42/Aβ40 endpoints. Wearable features have zero prediction weight because they did not add reliable information in the available cohort. The PET literature calculation uses an age prior and optionally the earlier measured task composite. Plasma values, PET positivity and brain tissue concentration remain separate endpoints. No brain Aβ concentration is measured or inferred.

The v1.1 browser implementation passed 171 numerical comparisons against the Python implementation, including sleep, quality gates, task references, calibration and PET probability. A regression check also covers restoring a preset after unverified sleep. Numerical agreement is a software check, not clinical validation. See the page's methods and source links for limitations.
